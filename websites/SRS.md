# SRS.md — Service (أدلة خدمات حكومية/تعليمية)

## Functional Requirements
- FR1: أدلة خطوة-بخطوة مصنّفة حسب الدولة: سوريا، السعودية، الإمارات، قطر، الكويت (مؤكَّد).
- FR2: تاريخ "آخر تحقق" ظاهر بكل دليل.
- FR3: تصنيف حسب الدولة + نوع الخدمة.
- FR4: روابط خارجية رسمية فقط، لا نسخ محتوى.
- FR5: تنبيه "تحقق من المصدر الرسمي" + إخلاء مسؤولية.
- FR6: بحث نصي، صفحات أساسية، إعلانات.

## Non-Functional Requirements
- Accuracy/Freshness: تذكير دوري (30/60 يوم) لإعادة التحقق — يحتاج عمود "بحاجة تحقق" بالـ Kanban التشغيلي.
- Accessibility: WCAG 2.1 AA.

## User Stories
US1: كمغترب سوري بالخليج، أريد دليلاً لتجديد جواز السفر من الخارج، حتى أنجز الإجراء دون أخطاء.
AC: يذكر الدولة والجهة الرسمية، "آخر تحقق" لا يتجاوز 60 يومًا، رابط مباشر للمصدر الرسمي.

## Use Case — قراءة دليل
Main Flow: عرض الخطوات → تاريخ آخر تحقق → رابط رسمي | Alternative: دليل منتهي الصلاحية → وسم "قيد إعادة التحقق" بدل الحذف.
